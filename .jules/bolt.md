## 2024-05-19 - N+1 Queries in Django DetailView
**Learning:** In Django, when a template iterates over related items (like `classroom.olympians.all`) and accesses a nested foreign key property (like `olympian.team.name`), it causes an N+1 query problem. Naively doing this in `get_context_data` without proper prefetching causes severe database performance issues on load. Blindly applying prefetch logic to base querysets used by UpdateView or DeleteView can result in over-fetching.
**Action:** Optimize `get_queryset` with `prefetch_related` using a `Prefetch` object that explicitly uses `select_related` for the nested foreign keys. Only apply this optimization in the `DetailView` or `ListView` where iteration happens, not globally across all views to prevent over-fetching.
