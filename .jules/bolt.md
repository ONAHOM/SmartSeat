## 2024-10-24 - [Avoid N+1 queries using Prefetch in Views]
**Learning:** In Django templates, iterating over related managers (e.g., `classroom.olympians.all`) can cause N+1 queries if nested relationships like foreign keys (e.g., `olympian.team`) are accessed. Putting related data in `get_context_data` (e.g. `context['olympians'] = self.object.olympians.all()`) doesn't inherently fix N+1 unless combined with prefetching.
**Action:** Optimize `get_queryset` with `prefetch_related` using a `Prefetch` object and `select_related` (e.g. `prefetch_related(Prefetch('olympians', queryset=Olympian.objects.select_related('team')))`). Avoid applying these heavy prefetches globally (like to `UpdateView` or `DeleteView`) to prevent over-fetching. Restrict them to views where the data is actually iterated over, like `DetailView` or `ListView`.
